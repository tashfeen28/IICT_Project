4. DYNAMIC DATA INTEGRATION & CHECKOUT FLOW
--------------------------------------------------------------------------------
The dynamic rendering engine is implemented in js/confirmation_26i-3272.js and
integrates with the checkout pipeline in js/checkout_26i-3272.js:

A. Order Placement Snapshot (js/checkout_26i-3272.js):
   - When the user places an order on pages/checkout.html, the submission handler
     validates inputs and packages a comprehensive immutable snapshot containing:
     orderId, timestamp, formattedDate, status ("Confirmed"), customer contact details,
     fulfillment preferences, payment method details, item list with normalized
     quantities and unit prices, subtotal, delivery fee, tax/service rate, grand total,
     prepTime, and instructions notes.
   - The snapshot is saved to localStorage under 'coffeeCircleLastOrder' and also
     prepended to the order history array in 'coffeeCircleOrders'.
   - The checkout confirmation card on pages/checkout.html provides a direct
     action button linking to pages/confirmation.html.

B. Data Retrieval & Normalization (js/confirmation_26i-3272.js):
   - The confirmation script automatically scans localStorage keys in priority order:
     'coffeeCircleLastOrder', 'coffeeCircleOrders', and legacy project keys.
   - Price Normalization: Uses parseMoney to strip out any currency symbols ("PKR",
     "Rs.", "$") and thousand separators, recalculating robust numbers.
   - Item Customization Normalization: Combines drink size specifications and add-on
     extras into a clear parenthetical label (e.g., "Regular (12 oz), +Extra Espresso Shot").
   - Fallback to Active Cart: If no completed order snapshot exists but an active
     cart is present in 'coffeeCircleCart', it gracefully builds a preview confirmation.
   - Empty State Handling: If neither a completed order nor cart data is found, it
     renders a clean "No Recent Order Found" card with a coffee icon, polite explanation,
     navigation links back to the home/menu pages, and a demo order loader for rapid testing.

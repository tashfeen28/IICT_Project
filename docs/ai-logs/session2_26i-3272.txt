      - Duplicate product IDs with different sizes/extras collided on quantity adjustments.

   1. Multi-Key Priority Scanner:

      - Supports both JSON arrays and wrapped object maps.
   2. Resilient Sanitizer & Value Parser:
      - parseMoney(): Strips 'PKR', 'Rs', '$', commas, and whitespace before parseFloat.
      - parseQty(): Reads both item.quantity and item.qty, defaulting to 1.
      - parseUnitPrice(): Evaluates unitPrice -> price -> basePrice -> amount -> cost -> rate -> (totalPrice / qty).
   3. Updated Usability Guard:
      - Accepts cart if any item has a valid name OR a parseable unitPrice > 0.
   4. Unique Line Fingerprinting:
      - cartLineId = productId + '||' + sizeLabel + '||' + extrasKey.
